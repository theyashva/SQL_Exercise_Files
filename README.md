# SQL Exercise Files

Practice assets for the LinkedIn Learning course "Learning SQL Programming." The repo includes a SQLite database, cross-DB scripts, and reference statements you can run while following the course.

## Contents
- `SQL_Exercise_Files/SQLite/quizdata.db` — SQLite database used in the lessons.
- `SQL_Exercise_Files/Other DBMS/quizdata_mysql.sql` — MySQL version of the sample data.
- `SQL_Exercise_Files/Other DBMS/quizdata_mssql.sql` — Microsoft SQL Server version of the sample data.
- `SQL_Exercise_Files/Notes/statements.md` — Example SQL statements from the course.

## SQL Playground
You can experiment with queries in the browser at https://qsql.vercel.app.
